# 종합 훈련 센터 변경 기록

[종합 훈련 센터(training-center.org)](https://training-center.org)의 서비스·앱 변경 기록입니다.
여기 적힌 내용은 공식 홈페이지의 [변경 기록](https://training-center.org/changelog) 페이지에 그대로 실립니다.

## 쓰는 규칙

- **회원이 읽는 글로 씁니다.** 내부 커밋 메시지·이슈 번호·코드 이름·서버 구조는 적지 않습니다.
- **보안 관련 수정은 "보안을 강화했습니다" 정도로만** 적습니다. 무엇이 어떻게 뚫렸는지는 쓰지 않습니다.
- 공개 채널에 싣지 않는 내용(성인향·통제 활동 등)은 적지 않습니다.
- 파일 하나가 배포 하루치입니다: `releases/YYYY-MM-DD.md`. 같은 날 여러 번 배포해도 한 파일에 모읍니다.
- 맨 위 머리말(front matter)에 날짜·제목·대상을 적고, 본문은 `### 새로 생긴 것` / `### 바뀐 것` / `### 고친 것` 순서로 씁니다(없는 칸은 뺍니다).

```markdown
---
date: 2026-10-19
title: 맥 앱 출시
platforms: [web, mac]
---

### 새로 생긴 것
- …
```

`platforms` 값: `web`(웹 서비스), `ios`, `android`, `mac`.
